# Nathan Ferdwiansyah W. - Portfolio

My personal website and digital playground. Built completely from scratch using Vanilla HTML, CSS, and JavaScript. 

No frameworks, no bloated libraries. Just clean code and math-driven UI design.

## The Setup
I built this to test how far I could push standard web technologies. Here's what's inside:
- **Math-driven 3D Tilt Cards**: Calculates cursor position and rotates cards in 3D space using raw CSS perspective.
- **Custom i18n System**: Translates the entire page (ID/EN) instantly without reloading, using a single JSON object.
- **Procedural SVG Noise**: A film-grain overlay generated with math, skipping the need for heavy PNG textures.
- **Custom Secret Terminal**: Hit the backtick key ( ` ) to open an interactive command line interface. Try running `whoami` or `projects`.
- **60FPS Canvas Particles**: A lightweight WebGL-style particle system built purely on the HTML5 Canvas 2D context.
- **Dynamic Micro-Interactions**: Features a custom cursor, magnetic buttons, UI click sounds, and a dynamic "Miss You" favicon when you switch tabs.

## Tech Stack
- **HTML5**: Semantic and clean structure.
- **CSS3**: Variables, clamps for fluid typography, custom scrollbars, and keyframe animations.
- **Vanilla JS**: DOM manipulation, event listeners, and animation loops (`requestAnimationFrame`).

## Run it locally
1. Clone this repo:
   ```bash
   git clone https://github.com/thannnajah-ai/portofolio.git
   ```
2. Open `index.html` in your browser. (Since it uses ES modules for the 3D Spline, a local server like Live Server or `serve` is recommended):
   ```bash
   npx serve .
   ```
